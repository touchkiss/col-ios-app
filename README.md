# col-ios-app
一个原生 iOS App，名称为 BioScope，用于展示全球物种百科。

整体要求：
- 严格遵循最新 Apple iOS Human Interface Guidelines
- 使用最新 iOS 的 Liquid Glass / 透明玻璃风格，但只用于导航、Tab Bar、悬浮控件等功能层
- 内容层不要过度毛玻璃，保持高级、清晰、现代、科技感
- 视觉风格偏未来科技、现代、自然科学、精品应用
- 界面要像 Apple 原生 App 一样克制、流畅、层级清晰
- 使用高质量自然生态图片 + 精致科学信息标签
- 组件可复用，适合后续 SwiftUI 落地

底部导航包含 4 个 Tab：
1. 首页
2. 全部
3. 收藏
4. 我的

首页：
- 风格参考苹果 App Store 首页的编辑式大卡片推荐布局
- 使用大尺寸沉浸式卡片推荐内容
- 包括“今日推荐物种”“深海奇观”“濒危物种”“雨林精选”等栏目
- 卡片点击后要有高级、精细、原生 iOS 风格的转场动画
- 动画特征包括：按压反馈、轻微缩放、层级过渡、流体展开、弹性回弹、背景模糊渐变
- 首页整体应有强烈的内容策展感，而不是普通工具 App

全部 Tab：
- 展示地球所有生物分类树
- 分类层级：Domain → Kingdom → Phylum → Class → Order → Family → Genus → Species
- 支持树状展开/折叠
- 顶部要有搜索、筛选、排序
- 支持 Tree / Categories / Map 三种查看方式
- 每个分类节点可展示代表物种卡片
- 使用后端提供的数据，这里先用示例数据做演示
- 布局要有“科学数据库 + 现代产品设计”结合的感觉

收藏 Tab：
- 展示用户主动收藏的物种与专题
- 支持列表和网格混合布局
- 支持按类群筛选，如哺乳动物、鸟类、海洋生物、植物、昆虫
- 有精致的空状态设计

我的 Tab：
- 展示用户资料、头像、统计信息、主题设置、通知设置、语言、离线下载、隐私与账号管理
- 增加成就感模块，例如“已浏览物种数”“已收藏数”“已探索地区数”
- 风格轻盈、整洁、高级

请生成以下关键页面：
1. 首页
2. 首页推荐卡片详情页
3. 分类树总览页
4. 分类详情页
5. 收藏页
6. 我的页

请使用这些示例物种数据进行视觉演示：
- 北极熊
- 美西螈
- 蓝鲸
- 银杏
- 雀尾螳螂虾
- 雪豹
- 巨杉
- 帝企鹅

配色建议：
- 主色调：深海军蓝、青蓝、青绿色、石墨灰、白色
- 点缀色：少量发光感青色或生态绿色
- 强调沉浸感、层次感、精致模糊、微发光、未来感
- 保持高可读性与真实可开发性

请输出高保真 iOS 移动端设计稿，多页面，并保持组件风格一致、可用于产品演示和原型展示。
